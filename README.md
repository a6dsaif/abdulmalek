# Abdulmalek Saif — Premium Portfolio

نسخة Premium من موقع السيرة الذاتية الشخصي.

## عدّل هذه البيانات
داخل `index.html` ابحث عن:
- `YOUR_EMAIL@example.com`
- `YOUR_USERNAME`

## CV PDF
ضع ملف السيرة الذاتية باسم:
`assets/Abdulmalek-Saif-CV.pdf`

## النشر
ارفع الملفات إلى GitHub Repository ثم:
Settings → Pages → Deploy from a branch → main → /(root) → Save

لا يحتاج الموقع إلى قاعدة بيانات أو Backend.
